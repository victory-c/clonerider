> **Seed status:** Claude Code draft (v0.1, lightly patched in v0.2). Per PRD Decisions log #2, the canonical `replay-viewer` spec is generated by Kiro from PRD §7.3 **without** this seed. This file is kept only for the "seed vs Kiro output" comparison. PRD §7.3 supersedes it (chase camera, gap ribbon, lead-change beats, committed style, per-segment trails, clip export moved to P2).

## Overview

This plan builds the `/ride` replay surface.

- **Stack:** MapLibre GL (`maplibre-gl@6.18.0`) + deck.gl (`deck.gl@9.4.1`, `@deck.gl/mapbox`, `@deck.gl/geo-layers`) + zustand.
- **Pure logic:** `lib/replay/*` holds the clock, formatting and layer data. It is property-tested with fast-check.
- **UI:** the React components follow `ui-haunt.md`.
- **Dependencies:** ghost-alignment task 7.2 (the worker `align` API) and ride-ingest task 11 (sample ghosts).
- **APIs:** use the Context7 MCP to confirm the current MapLibre / deck.gl APIs before writing integration code.
